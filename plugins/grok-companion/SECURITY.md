# Security Policy

## Supported version

Security fixes are provided for the latest released version of Grok Companion.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub Security Advisories:

https://github.com/mmm1h/codex-grok-companion/security/advisories/new

Include the affected version, operating system, reproduction steps, impact,
and any proposed mitigation. Do not include live credentials or proprietary
repository data. Please allow a reasonable period for investigation and a
coordinated fix before public disclosure.

General bugs and support questions belong in the public issue tracker:
https://github.com/mmm1h/codex-grok-companion/issues
